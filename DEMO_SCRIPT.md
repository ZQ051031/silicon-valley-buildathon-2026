# StudySprint demo (2 minutes 35 seconds)

Before recording, start the local server and open the app in a fresh browser profile. Have a terminal ready with `npm test`.

| Time | Show and say |
| --- | --- |
| 0:00–0:15 | Open the study desk. “StudySprint helps me get started, decide what’s next, and remember what I learn. Everything stays in this browser; there’s no account.” |
| 0:15–0:35 | Open **Timer settings**, set focus to **1** minute and break to **2**, save, start, briefly pause, then resume. “Completed focus blocks count; abandoned ones don’t.” Keep it running through the next steps. |
| 0:35–1:02 | Add **Outline the history essay** with High priority and today’s date. Open **Due today**, edit it to **Draft the history essay**, mark it complete, then show it in **Done**. |
| 1:02–1:30 | Add **What is active recall?** / **Retrieving information from memory without looking.** Read the prompt before revealing the answer, then choose **Hard**. Point to the scheduled date and the empty due queue. “Again brings it back tomorrow; Easy gives it more time.” |
| 1:30–1:53 | Return to the timer just after the minute ends. Show **1 session**, open **Session log**, and point out the break ready to start. Reload the page and show that the log, completed task and next review date remain. |
| 1:53–2:24 | Run `npm test`. Call out the timer deadline, task filtering, and leap-day scheduling checks. Explain why the browser test simulated elapsed time and reloaded: a timer that looks right on-screen can still lose its state on refresh. |
| 2:24–2:35 | Briefly show the stacked mobile layout. Close with: “One task, one focus block, one thing remembered.” |
